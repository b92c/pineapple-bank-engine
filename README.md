# Pineapple Bank — Engine (Backend)

Pineapple Bank é um protótipo de fintech voltada para investimentos e cofrinhos, desenvolvido como um Dojo de engenharia de software. O objetivo central é construir um sistema backend distribuído real, com toda a complexidade técnica que esse tipo de sistema exige.

Este repositório contém a **Engine (Backend)**, desenvolvida em Go usando gRPC, Kafka, PostgreSQL, Redis e uma arquitetura baseada em microserviços orientada a eventos.
